# Font Reviver

**revive your ancient, dead fonts**

Recover legacy collections using a portable Python engine, local browser app, CLI, JSON API and Agent Skills instructions. Existing modern formats remain unchanged; recoverable legacy outlines become OTFs. Originals and cloud placeholders are preserved. No font files ship with the project.

Scope includes documented input formats, metrics matching, Mac resource/AppleDouble/ZIP extraction, FontForge conversion and metadata escaping, validation, reports, and an expandable searchable gallery. The app operates locally; no hosting, domain, account or cloud service is required.
